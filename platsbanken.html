Data från Arbetsförmedlingens öppna API (JobSearch / Platsbanken), både offentliga och privata arbetsgivare. Filtrerar på samma strukturerade yrkesgrupp som Platsbankens eget filter. Län-listan fylls på med de län som förekommer i träffarna.
